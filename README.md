🏨 Hotel Reservation System

Sistema de reservas de hotéis desenvolvido com React e Bootstrap, focado em oferecer uma interface moderna, responsiva e intuitiva para usuários que desejam consultar hospedagens e realizar reservas online.

📌 Sobre o Projeto

Este projeto está em desenvolvimento e atualmente possui uma estrutura visual funcional para simular um sistema de reservas de hotéis.

No momento, a aplicação conta com:

Página inicial responsiva
Interface moderna utilizando Bootstrap
Seção de hotéis e informações visuais
Botão de disponibilidade
Formulário para preenchimento de dados do usuário
Navegação fluida entre componentes

Apesar da interface já estar funcional, algumas funcionalidades ainda estão em fase de implementação, como o envio real das reservas e integração com backend.

 Integração com backend

 Armazenamento de reservas

 Integração com pagamentos

 🎯 Objetivo

O principal objetivo deste projeto é evoluir gradualmente para um sistema completo de reservas de hotéis, aplicando conceitos de desenvolvimento frontend e futuramente backend, autenticação, APIs e banco de dados.

Além disso, o projeto também serve como prática de desenvolvimento Full Stack e construção de portfólio.
